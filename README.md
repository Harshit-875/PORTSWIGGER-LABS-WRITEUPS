# PORTSWIGGER-LABS-WRITEUPS

This repository contains my hands-on writeups and solutions for PortSwigger Web Security Academy labs. The goal of this repository is to practice web application security, understand vulnerabilities, and improve penetration testing skills through practical labs.

* SQL Injection (SQLi)
* Cross-Site Scripting (XSS)
* Authentication Vulnerabilities
* Access Control
* CSRF
* SSRF
* File Upload Vulnerabilities
* Command Injection
* Path Traversal
* Business Logic Vulnerabilities
* Clickjacking
* XXE Injection
* Information Disclosure
* Web Cache Poisoning
* And more...
